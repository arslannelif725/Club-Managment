# AGÜ Data Club Management System (`AguDataWeb`)

A professional, lightweight, server-side Java web application designed to streamline student club administration, task assignment, member tracking, and real-time announcements.

## 🚀 Features

- **Multi-User Authentication & Role-Based Access Control (RBAC):** Distinct views and privileges for Coordinators/Admins and Normal Members.
- **Task Management System:** Assign tasks to specific members or roles, track progress ("Pending" vs. "Success"), and update status interactively.
- **Club Groups & Member Directory:** Create groups, target specific roles, and manage member assignments.
- **Announcements Broadcasting:** Persistent club-wide announcements with author attribution and timestamps.
- **Pure Java Architecture:** Built using Java's native `HttpServer` and `JDBC` without heavy frameworks, ensuring high performance and lightweight deployment.

## 🛠️ Tech Stack

- **Backend:** Java (Standard `HttpServer`, `JDBC`, `StandardCharsets`)
- **Database:** MySQL
- **Frontend:** Pure HTML5/CSS embedded via dynamic Java server responses (UTF-8 supported)
